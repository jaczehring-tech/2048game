Repository for a 2048 game in the terminal. 2048 is a puzzle game where you slide numbered tiles across a grid while trying to combine them with like tiles, and you try to go as high as you can until you run out of moves. MVP will be a simple, functional game of 2048 in the terminal. To play, make a git clone, cd to the directory, use javac, then java. I plan on implementing the core features of 2048 one at a time until the base game is complete, and then I'll try to add things such as saving and loading games, special rules, and better terminal display.
